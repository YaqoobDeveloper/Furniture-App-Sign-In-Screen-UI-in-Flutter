# Furniture App Sign-In Screen UI in Flutter 🛋️✨

A modern and clean **furniture app sign-in screen UI** built with Flutter.

This project focuses on a polished furniture-themed authentication experience with a clean layout, reusable widgets, and responsive design.

## ✨ Features

- 🛋️ Modern furniture app sign-in UI
- 🎨 Clean and minimal design
- 🔐 Email and password sign-in fields
- 👤 Remember me option
- 🔵 Social sign-in buttons
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean project structure

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Furniture-App-Sign-In-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Furniture-App-Sign-In-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
